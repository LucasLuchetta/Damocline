## Current platform evidence

- PRs #57 through #88 are merged, including native-engine trusted TLS, truncated-body and response-size-boundary reconciliation, exact workload-shape calibration, transport failure ledgers including DNS SERVFAIL, sampler wall-time screening, and per-profile TCP connection ledgers. The controlled positive soak is validated on Windows and in Docker Desktop/WSL2 Linux; bare-metal Linux remains pending.
- The controlled positive soak ran on 12 logical CPUs and reconciled 300 client arrivals/completions with 300 independent child-fixture completions. Its private report is preserved under `.damocline/calibration/controlled-positive-2026-10-18-final.json` (gitignored).
- Windows AMD64, Go 1.26.3, 12 logical CPUs: historical schema-v4 basic, extended, and repeat runs remain as recorded below; new schema-v5 acceptance passed twice with 30 exact profile pairs per run, 980/980 aggregate independent server requests, zero ledger discrepancies, and 300/300 controlled soaks recalculated as `VALID_WITHIN_ENVELOPE`. The separate HTTP/HTTPS transport matrix passed 10/10.
- Linux AMD64 under Ubuntu 22.04 on WSL2, Go 1.26.3, 12 reported logical CPUs: schema-v5 acceptance passed twice with the same 30-profile and 980/980 aggregate ledger gates, 300/300 controlled soaks recalculated as `VALID_WITHIN_ENVELOPE`, and 10/10 transport cases. The binary ran as Linux amd64, but the kernel/runtime environment is WSL2 on the same physical Windows host; this is not independent bare-metal Linux or cross-host validation.
- Linux AMD64 in Docker Desktop with its WSL2 backend, Go 1.26.3, cgroup v2 finite quota 4, 12 logical CPUs, and `GOMAXPROCS=12`: schema-v7 repeated acceptance passed twice with the hierarchical quota reader. Each run reconciled 30/30 exact profiles and 980/980 independent server requests; soak quality recomputed positive, and 10/10 transport cases passed. Both manifests recorded `cgroup_v2_cpu_quota_hierarchy`; new evidence is preserved in the ignored `.damocline/acceptance/docker-cgroup-hierarchy-schema7-20261019/` directory. This validates that recorded container setup only, not a separate physical host or bare-metal Linux.

## G0 exit decision

G0 remains **open**. Positive results are established only for the controlled Windows and recorded Docker Desktop/WSL2 loopback soaks. Cross-host/hardware-class equivalence, bare-metal Linux, broad transport/failure matrices, statistical dependence handling, and multiple other G0 acceptance gaps remain.
