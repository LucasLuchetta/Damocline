# ADR 0088: Calibrate trusted HTTPS generator profiles

## Status

Accepted (experimental).

## Context

The native engine already had a regression test for trusted local TLS, while
the bounded preflight matrix only measured HTTP workload profiles. That meant
the exact calibration gates could not cover HTTPS generator delivery and a
TLS scenario could not distinguish unmeasured scheme from an exact local
profile. Standalone transport tests did not run the native scheduler or retain
the same client/server ledgers as the preflight.

## Decision

Advance calibration preflight to schema v8. Preserve schema-v3 through v7
profile matrices exactly for archived records. Keep the existing 30 HTTP
shape/rate/connection-policy tuples and add one 4 KiB GET response profile at
each exact 2, 5, and 10 journey starts/s rate over HTTPS with connection reuse.
Use a new self-signed certificate generated by the child fixture process for
each calibration run. The child sends only the public certificate over its
local stdout pipe; the private key remains in child memory. The parent trusts
that certificate only in its calibration-local HTTP transport. TLS is limited
to TLS 1.2+ over HTTP/1.1 so the expected one reused TCP connection and one
client-observed TLS handshake can be reconciled.

Persist client TLS-handshake counts with the existing profile observations.
Require exactly one handshake for each reusable HTTPS profile and zero for
HTTP profiles, alongside the existing independently counted request, body,
and TCP-connection ledgers. Update the bounded repeated acceptance lab to
require the schema-v8 profiles and both client/server evidence.

## Consequences

The opt-in calibration gate can now qualify only the exact named HTTPS GET
shape, connection policy, control tuple, and short rates in a schema-v8
artifact. Older artifacts remain HTTP-only and readable. Certificate trust is
ephemeral and process-local; no insecure TLS bypass or remote target is used.
This does not calibrate TLS timing accuracy under load, HTTP/2, new-per-request
HTTPS, other payloads, endpoint identity, or application capacity. The
calibrator remains bounded to 240 seconds, with a 235-second child-fixture
lifetime.
