# ADR 0013: Restrict custom TLS roots to local reference fixtures

## Status

Accepted.

## Context

The local transport calibration must exercise trusted HTTPS deterministically without weakening certificate verification or relying on public network services. Production scenarios must continue to use the platform trust store and normal hostname verification.

## Decision

Expose an optional TLS root pool only through the internal validated engine configuration. The calibration command supplies the certificate authority generated by its own loopback HTTPS fixture. The public CLI does not accept arbitrary roots, and the default transport behavior remains unchanged when no pool is supplied.

## Consequences

The reference matrix can verify trusted and untrusted HTTPS locally and reproducibly. This seam is internal and intended for controlled fixtures; it does not establish general TLS performance or validate production certificates, DNS, or network paths.
